# Sicherheit

## Eine Schwachstelle melden

Bitte **kein** öffentliches Issue. Nutze GitHubs privates Meldeformular:
[Security → Report a vulnerability](https://github.com/lukasboc/barrierepruefung-wordpress/security/advisories/new).

Wir bestätigen den Eingang und melden uns mit einer Einschätzung zurück.

## Unterstützte Versionen

Sicherheitskorrekturen erscheinen für die jeweils aktuelle Nebenversion.

## Was das Plugin überträgt

Adresse der Website, das vom Betreiber erzeugte API-Token und die Kennung der Website im
Dienst — an die unter *Werkzeuge → Barrierefreiheit* eingetragene Adresse. Keine Inhalte und
keine personenbezogenen Daten von Besucherinnen und Besuchern.
